BUILD THE APK (no Android Studio needed)
1. Create a free GitHub account, make a new repository.
2. Upload ALL files/folders from this zip (keep the .github folder).
3. Open the Actions tab > "Build APK" > wait ~5 min.
4. Open the finished run > Artifacts > download DeepClean-apk, unzip, install app-debug.apk.
Or open this folder in Android Studio and press Run.
